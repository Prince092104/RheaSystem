# 🎯 SETUP INSTRUCTIONS

## 📋 What Was Created

Your **File-Based Calendar System** is now ready in:
```
c:\xampp\htdocs\RhealynSystem\
```

## 🚀 Three Steps to Use

### Step 1️⃣: Start XAMPP
1. Open **XAMPP Control Panel**
2. Click **Start** button next to **Apache**
3. Wait for green indicator (takes 2-3 seconds)

### Step 2️⃣: Open Browser
1. Open any web browser (Chrome, Firefox, Edge, etc.)
2. Paste this URL in address bar:
   ```
   http://localhost/RhealynSystem/
   ```
3. Press **Enter**

### Step 3️⃣: Create Your First Event
1. Type event title (e.g., "Team Meeting")
2. Select date
3. Click **Create Event**
4. Done! ✅
